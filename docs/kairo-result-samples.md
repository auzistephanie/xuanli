# Kairo 結果頁樣本（10 則，供審）

這十則只給你看語氣和格式。尚未寫入 `combos.json`，app 程式也沒有改。

樣本用書面語。角色名先講這個人在做什麼，不再用「林間清泉」「雪嶺孤松」這類要猜的比喻。

本月以 2026-10-13 為準：農曆九月初四，月柱戊戌。提醒按這個土月來寫，換月就要重算。

## 鍵是怎麼來的

查過 `lib/data/combos.json` 和取值的程式，結論如下。

- 共 160 筆，沒有缺，也沒有重複。
- 鍵的格式是 `日柱天干_MBTI`，例如 `庚_ESTJ`。程式在 `getCombo()` 裡把日柱第一個字和 MBTI 拼起來查表（`lib/models/combo.dart`）。
- 日柱取自八字第三柱（日柱）。揭曉頁、組合頁、分享卡都是 `pillars[2]` 的第一個字，不是年柱，也不是月柱（`reveal_step.dart`、`combo_screen.dart`）。
- 十個天干齊全，就是甲、乙、丙、丁、戊、己、庚、辛、壬、癸。每一干各配 16 型 MBTI。
- 天干對五行（`lib/engine/wuxing_tables.dart`）：甲乙木、丙丁火、戊己土、庚辛金、壬癸水。畫面上的「庚金」是天干加五行，不是鍵本身。鍵只存「庚」。

下面十則蓋過全部十干。指定的六組都在。另外四組補上還沒出現的丁、戊、辛、壬。

1. 十種日主，十六種性格。先看你是哪一種人。
2. 出生日的天干對上性格，給你一個看得懂的名字。
